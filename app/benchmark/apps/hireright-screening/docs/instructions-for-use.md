# HireRight Screening: instructions for use (recruiting teams)

**Provider:** ACME Corp, Talent Technology, Rue de la Loi 1, 1000 Brussels;
support: hireright-support@acme.example.

## 1. Intended purpose
Ordering applications for an open requisition so that you review the most relevant ones first.
The ranking is a recommendation. You remain responsible for every decision.

## 2. How to use the ranking
* Read the main reasons shown next to each score (▲ increased / ▼ decreased the score).
* Applications marked "unranked" could not be scored; review them like any other application.
* Every candidate must be opened before you advance or reject them; rejections require a written
  reason.

## 3. Human oversight
* **Move** lets you disregard the ranking for a candidate.
* Screening admins can suspend automated ranking for all requisitions from the admin page; the queue
  then falls back to chronological order.
* Mandatory training "Working with AI recommendations" (45 min) before getting the recruiter role.
