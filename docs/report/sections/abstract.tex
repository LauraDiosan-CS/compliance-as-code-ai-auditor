\section*{Abstract}
\noindent
The EU AI Act~\cite{euaiact2024} and GDPR~\cite{gdpr2016} ask AI systems to keep logs, tell users when they talk to an
AI, let a human stop the system, and more. Today, checking an application against these rules is a slow, manual audit.
We build a \emph{Compliance-as-Code AI Auditor}. It turns a policy into 45 testable requirements and a code repository
into small pieces of evidence. Each requirement is then decided in one of three ways: fixed rules, an LLM judge (Claude
Sonnet) that must cite its evidence, or a hybrid that asks the LLM only when the rules are unsure. We test them on five
AI applications that we labelled by hand (165 labels). The hybrid is the most accurate (86.1\%, against 79.4\% for the
rules and 71.5\% for the LLM) and costs \$0.67 instead of \$4.81. The LLM alone is the only method that never calls a
real gap compliant, and every citation is valid.
