\chapter{Conclusion and future work}
\label{chapter:concl}

We defined the task of checking a repository against a policy, with a status, a confidence and cited evidence for each
requirement. We built a pipeline that turns policies and repositories into an audit report, and we compared three
decision methods on five hand-labelled applications. The v0 hybrid is the most accurate (86.1\%) at a fraction of the
LLM cost. The LLM alone is the safest: it never calls a real gap compliant. Every error comes with the evidence that
caused it, so it can be found and fixed.
